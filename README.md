# COIN BRAWL

Кликер: +1 монета за клик, прокрут карточек, батлы и прокачка HP.

## Запуск бэкенда

```bash
npm install
npm start
```

Redis: `fi14.bot-hosting.cloud:25299`

Фронт раздаётся с того же сервера (`/`) или как GitHub Pages. Если страницы на Pages, а API локально — в консоли:

```js
window.CBS_API = 'https://your-backend';
```
